# Roblox Model Exports

Store recoverable Roblox model files from The burg in this folder.

## Recommended files

- `Burg_InteractiveHouses.rbxm`
- `Burg_ExteriorHouseCollection.rbxm`
- `Burg_TheVibe.rbxm`
- `Burg_LuxuryOnly.rbxm`
- `Burg_MarketSquarePlaza.rbxm`
- `Burg_SchaumburgHighSchool.rbxm`
- `Burg_TownSquareAndRoads.rbxm`
- `Burg_DreamWorld.rbxm`

## Export procedure

1. Open The burg in Roblox Studio.
2. Select the exact Model or selected model collection in Explorer.
3. Use **Save to File** / **Save Selection to File**.
4. Choose this `Model Exports` folder and save as `.rbxm` or `.rbxmx`.
5. Do not overwrite an older known-good export without keeping a dated copy.
6. Record the export date and source Studio path in [[23 - Burg Model Transfer Catalog]].

Obsidian stores these files as attachments. Roblox Studio is still required to inspect or insert their actual Instances.
