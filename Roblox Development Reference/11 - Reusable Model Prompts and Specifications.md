# Reusable Model Prompts and Specifications

## Detailed Pulse prop prompt

Create a polished Roblox handheld electronic prop matching the distinctive rounded silhouette of the supplied reference. Preserve the rounded purple body, raised chrome-bordered vertical screen, short top extension, and compact handheld proportions. Do not redesign it as a phone or generic box.

Use a smooth lavender-purple rounded body, a glossy black front display, a thick silver metallic border, and a short rounded top mouthpiece. The screen should contain green curved LED indicators, purple segmented numbers, small orange indicators around a dark center, and subtle glass reflections.

Replace all original product branding with only `Pulse` in clean white text. Do not include `GEEK BAR` or `GEEK CAR`. Add the small purple planet and thin yellow orbital rings near the lower side panel when the reference calls for it.

Target approximately 1.3 studs tall, 0.6 studs wide, and 0.4 studs thick. Include organized components, a `Handle`, and a correctly aligned `GripAttachment`. The screen must face outward while held. Use optimized geometry, SmoothPlastic, Metal, Glass, and limited Neon details.

## Simple blocky version

Create the same recognizable Pulse silhouette using a small number of clean Roblox Parts. Keep the purple body, black screen, silver border, and top extension. Prioritize a solid blocky style, correct proportions, and reliable Tool behavior over tiny decorative details.

## Black device reference rule

For the black rectangular device reference:

- Preserve the compact rounded body and top mouthpiece.
- Remove all original side branding.
- Use custom Pulse branding only if requested.
- Keep a dark technological face design with simple constellation/star graphics.
- Make it Tool-compatible and sized for an NPC/player hand.

## Filler-house prompt template

Create a polished exterior-only Roblox suburban filler house inspired by the supplied reference. Match the major massing, roof arrangement, garage position, window rhythm, front entry, siding color, driveway, and basic landscaping. Do not build interior rooms or furniture. Keep the inside hollow, but ensure the exterior shell is fully closed from every angle.

Use clean aligned Parts, complete gable walls, believable roof overhangs, fascia, gutters, corner boards, framed dark glass windows, finished doors, foundation trim, and restrained shrubs. Avoid floating windows, random walls, roof gaps, protruding wall pieces, and mismatched colors. Organize the model into exterior folders and anchor every part.

## Modular-road prompt template

Create a Roblox modular road kit with a straight road, sidewalks on both sides, four-way intersection, left turn, and right turn. Every piece must share the same road width, curb dimensions, sidewalk elevation, lane marking positions, thickness, and connector alignment. Set consistent pivots or connector Attachments so pieces snap together without gaps or overlaps.
